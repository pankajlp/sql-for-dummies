# SQL for Dummies: Byte's SQL Quest

A playful, animated SQL course for kids and beginners (about 5th-grade level), made to be ADHD-friendly: tiny steps, lots of rewards and brain breaks.

Your guide is **Byte**, a little database mascot. Every query runs on a real SQLite engine ([sql.js](https://github.com/sql-js/sql.js)) right in the browser.

## What's inside

- **Brain Camp**: how to learn (mistakes = brain XP, tiny bites, guess first, teach it back, a little every day) and how to think (the 4 Detective Questions).
- **8 worlds**: SELECT, WHERE, ORDER BY, LIKE/IN/NULL, aggregates and GROUP BY, JOINs, INSERT/UPDATE/DELETE/CREATE, then CASE, subqueries, WITH and window functions.
- **4 boss battles** with hearts and boss health bars, plus a graduation certificate.
- **Arena**: 13 HackerRank/LeetCode-style puzzles (easy, medium, hard).
- **Real-life projects**: Pizza Palace, School Library, the Great Cookie Mystery, Sports Day Scoreboard.
- **Rewards**: XP, levels, coins, badges, and a closet of hats and colors for Byte.
- **Daily tracker**: daily goal, streak, calendar, last-7-days chart, minutes learned, and a learning journal.

## Run it

It's a single file. Open `index.html` in a browser (needs internet for the fonts and the SQL engine), or turn on GitHub Pages for this repo.

Progress is saved in the browser's local storage.
